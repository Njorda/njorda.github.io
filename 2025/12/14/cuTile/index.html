Cutile kernel in pytorch

Posted on Dec 14, 2025

In this blog post will we try to play around with one of Nvidias latest releases that seems to be the next progression interms of writing Cuda Kernels, cuTile.

A youtube video tutorial can also be found here and a deep dive in the arch and background here

The official release docs of cuTile is avialble here but the possibly better intro to it is here with the tldr:

| NVIDIA Finally Adds Native Python Support to CUDA

That is also one of the key take aways, the second key take way of cuTile is the core of how things are set up in terms of the programing model. It is expressed as “the key in cuTile is operations done on arrays” the effect of this is that kernels are developed slightly different than from Cuda code where the mental model is about “threads”. This allows developers to write code that is slightly more high level and cuTile take care of mapping tiles to cuda threads. Kind of the goal for cuTile is to allow you as a developer to focuse on the kernel and dont have to focuse on the GPU hardware specifics.

While this sounds good, lets try it out and see the difference instead.

Feel free to use any GPU based upon Blackwell, I will do it through RunPod
